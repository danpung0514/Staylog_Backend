## 개요
> 사용자가 여행지와 관련된 리뷰와 정보를 공유할 수 있고 숙소를 탐색하고 예약할 수 있는 리뷰 기반 커뮤니티 웹 서비스 입니다.
- 프로젝트 팀 구성: 백엔드, 프론트엔드 풀스택 개발자 9명
- 프로젝트 기간: 2025-10-13 ~ 2025-11-12

## 링크

- [**배포 링크**](https://staylog.store)

## 기술 스택 (Tech Stack)

이 프로젝트에서 사용된 주요 기술 스택은 다음과 같습니다.

### Frontend
| 카테고리 | 스택 | 설명 |
| :-- | :-- | :-- |
| **프레임워크** | React | 컴포넌트 기반 아키텍처를 활용하여 SPA를 구축했습니다. |
| **언어** | TypeScript | 정적 타입을 사용하여 코드의 안정성과 유지보수성을 높였습니다. |
| **UI 라이브러리** | Bootstrap | 반응형 디자인과 일관된 UI 스타일링을 위해 사용했습니다. |
<br>

### Backend
| 카테고리 | 스택 | 설명 |
| :-- | :-- | :-- |
| **프레임워크**	| Spring Boot	| Spring 기반 애플리케이션을 쉽게 빌드하고 실행하기 위해 사용했습니다. |
| **언어**	| Java	| 안정적이고 강력한 객체 지향 언어로 비즈니스 로직을 구현했습니다. |
| **보안**	| Spring Security	| 인증(Authentication) 및 권한 부여(Authorization)를 처리했습니다. |
| **인증 방식**	| JWT (Json Web Token)	| 클라이언트-서버 간의 상태 비저장(Stateless) 인증을 구현했습니다. |
| **데이터 접근**	| MyBatis	| SQL 쿼리를 XML 파일로 분리하여 데이터베이스 접근 로직을 관리했습니다. |
| **API 문서화**	| Swagger	| API 엔드포인트를 시각적으로 문서화하고 테스트할 수 있도록 했습니다. |
<br>

### Database
| 카테고리 | 스택 | 설명 |
| :-- | :-- | :-- |
| 데이터베이스 | Oracle DB | 신뢰성 높은 데이터 저장 및 관리를 위한 RDBMS를 사용했습니다. |
<br>

### DevOps & Infrastructure
| 카테고리 | 스택 | 설명 |
| :-- | :-- | :-- |
| **배포 환경 (서버)** | AWS EC2 | 클라우드 기반 가상 서버 인스턴스에 애플리케이션을 배포했습니다. |
| **컨테이너화** | Docker | 애플리케이션과 환경을 컨테이너화하여 일관된 배포 환경을 보장했습니다. |
| **웹 서버/프록시** | Nginx | EC2 인스턴스에서 리버스 프록시 및 정적 파일 서빙을 담당했습니다. |
| **CI/CD** | GitHub Actions | 코드 푸시 시 자동으로 빌드, 테스트, 배포되도록 파이프라인을 구축했습니다. |
<br>

### 협업 및 버전 관리
| 카테고리 | 스택 | 설명 |
| :-- | :-- | :-- |
| 버전 관리 | Git | 코드 변경 이력 추적 및 관리했습니다. |
